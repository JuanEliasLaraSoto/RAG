# Python

Python es un lenguaje de programación de alto nivel creado por Guido van Rossum y publicado por primera vez en 1991. Su filosofía pone énfasis en la legibilidad del código.

En Python las listas son mutables y se escriben con corchetes, mientras que las tuplas son inmutables y se escriben con paréntesis. Los diccionarios guardan pares clave-valor.

Para instalar paquetes se usa pip, por ejemplo `pip install requests`. Se recomienda trabajar dentro de un entorno virtual creado con `python -m venv .venv`.
